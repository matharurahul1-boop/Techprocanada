# Crimson Glass Theme

## Goal
Apply the selected crimson glass direction across the existing TechPro app without changing any workflows or page layouts.

## Changes
- Replace the blue accent system with a deep crimson-to-red brand palette.
- Shift the canvas to a dark neutral red-black backdrop with restrained red ambient light.
- Restyle the floating navigation, top bar, content panels, forms, and drawers as readable frosted-glass surfaces.
- Use red gradients for selected navigation, table headers, primary actions, toggles, and pagination.
- Preserve green, amber, and red status meanings and maintain strong contrast.
- Keep mobile navigation, tables, forms, and all existing interactions responsive and unchanged.

## Technical details
- Update semantic colors and reusable glass/gradient utilities in the global design system.
- Update shared shell and sheet treatments so every screen inherits the theme consistently.
- Replace remaining non-semantic overlay and ring colors in the shared surfaces.
- Verify representative list, inventory, and log screens at desktop and mobile sizes.
